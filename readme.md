# BookTrack

BookTrack er vefur þar sem notandi getur haldið utan um bækur sem hann hefur lesið. Hægt er að bæta við bókum, gefa þeim einkunnir, leita að bókum og raða þeim.

## Keyrsla

Setja upp pakkana:

npm install

Keyra vefinn:

npm run dev

## Tæki og tól

- HTML
- CSS
- JavaScript
- Parcel
- ESLint
- Stylelint

Lint:

npm run lint
npm run lint:css

Build:

npm run build

## Uppsetning

- index.html – Uppbygging vefsins.
- styles.css – Útlit vefsins.
- script.js – Virkni vefsins.
- package.json – Verkefnisstillingar og skipanir.
- package-lock.json – Útgáur pakkasafna.

Bækur eru vistaðar í localStorage svo þær haldist eftir endurhleðslu.

## Virkni

- Bæta við bókum.
- Gefa bókum einkunn.
- Leita eftir titli og höfundi.
- Raða eftir titli, höfundi og einkunn.
- Vista bækur í localStorage.
